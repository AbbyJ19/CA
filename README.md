Project Description

My Contact Management System is a PHP project designed to manage contact information. It provides a basic structure for working with contact details using PHP and a database.

Project Files

* index.php — The main entry page of the application.
* dashboard.php — The dashboard page.
* submit.php — Processes submitted form information.

Technologies Used

* PHP
* MySQL/MariaDB
* HTML
* CSS, if used in the project

How to Run the Project

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Place the project folder inside the htdocs directory.
4. Create and configure the required database if it has not already been created.
5. Open a browser and visit http://localhost/CA/.
